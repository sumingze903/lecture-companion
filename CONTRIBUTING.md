# Contributing

Thanks for helping improve Lecture Companion.

Good first contributions:

- Improve the academic phrase dictionary in `src/hooks/use-transcription.ts`
- Add browser compatibility notes
- Improve sentence boundary detection
- Add optional AI summary support
- Improve accessibility and mobile layout

Before opening a pull request:

```bash
npm run typecheck
npm run build
cd server
npm run typecheck
npm run build
```

Please do not include real lecture recordings, transcripts with personal information, or API keys in issues or pull requests.
